# Skill: Design Intake and UI Scope

## Purpose

Use this skill when design direction exists in screenshots, mockups, references, or rough UI notes and needs to be turned into implementation scope.

## Good use cases

- new UI work
- redesigns
- dashboard styling updates
- design inspiration to implementation planning
- feature work with strong visual expectations

## Workflow

1. Gather the reference materials.
2. Identify target screens, states, and interactions.
3. Separate visual goals from functional goals.
4. Identify reusable components and one-off elements.
5. Identify unanswered questions that affect implementation.
6. Define review checkpoints before coding everything at once.

## Output format

- references
- target screens
- visual goals
- functional goals
- reusable components
- open questions
- review checkpoints

## Guardrails

- do not treat one screenshot as the full design system automatically
- distinguish required fidelity from inspiration-only direction
- identify missing states early
- keep scope visible before polishing details
