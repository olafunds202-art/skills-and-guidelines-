# Skill: On-Page SEO and Metadata

## Purpose

Use this skill when pages need search-friendly metadata, clear structure, and correct indexing basics.

## Good use cases

- page launches
- site refreshes
- SEO cleanup work
- metadata QA before go-live
- social-preview validation

## Workflow

1. Identify the page purpose and target intent.
2. Review title, description, URL, heading structure, and canonical assumptions.
3. Review internal links and anchor clarity.
4. Review indexing controls, robots assumptions, and duplicate-page risks.
5. Review social preview metadata.
6. Record missing or weak metadata.

## Output format

- page
- intent
- title status
- description status
- heading structure notes
- indexing notes
- social preview notes
- follow-up actions

## Guardrails

- do not stuff keywords unnaturally
- do not leave default or duplicate metadata in place
- keep metadata aligned with actual page content
- be explicit when a page should be noindex or protected
