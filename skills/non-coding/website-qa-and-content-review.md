# Skill: Website QA and Content Review

## Purpose

Use this skill when a website or content-heavy page needs a structured review before launch or after major updates.

## Good use cases

- pre-launch checks
- client review rounds
- staging review
- content migration QA
- page-by-page quality review

## Workflow

1. Review pages against the approved brief or content plan.
2. Check copy, headings, links, images, and CTA behavior.
3. Check mobile and desktop rendering.
4. Check empty states, error states, and fallback content where relevant.
5. Check brand and consistency issues.
6. Record blockers vs nice-to-have polish.

## Output format

- pages checked
- issues found
- severity
- screenshots or notes
- blockers
- follow-up list

## Guardrails

- do not mix critical launch blockers with minor polish comments
- note content errors separately from visual or technical issues
- verify the page against purpose, not only against aesthetics
- leave a usable issue list for follow-up work
