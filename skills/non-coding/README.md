# Non-Coding Skill Family

These skills cover important work that surrounds implementation but is not purely code writing.

## Included starter skills

- `research-workflow.md`
- `debugging-and-investigation.md`
- `bug-reproduction-and-triage.md`
- `root-cause-analysis.md`
- `incident-report-and-handoff.md`

## When to use

Use these when the job is to:

- investigate before building
- diagnose a bug or regression
- reproduce an issue reliably
- explain root cause clearly
- produce a handoff after an incident or difficult debugging session

## How they fit with coding skills

A common sequence is:

1. research or investigate
2. reproduce and isolate
3. identify root cause
4. implement the fix with the relevant coding and stack skills
5. verify and document the outcome
