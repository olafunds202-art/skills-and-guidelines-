# Skill: Content Structure and Page Planning

## Purpose

Use this skill when a site or page needs clearer structure before or during implementation.

## Good use cases

- landing pages
- brochure sites
- service pages
- content-heavy websites
- redesigns where layout and message need clearer hierarchy

## Workflow

1. Define the page goal.
2. Identify target audience and search or user intent.
3. Define the primary CTA.
4. Break the page into sections in logical order.
5. Identify content dependencies for each section.
6. Check whether internal links and related pages support the journey.
7. Record gaps in content or messaging.

## Output format

- page goal
- audience and intent
- CTA
- section outline
- dependencies
- internal link notes
- content gaps

## Guardrails

- do not design pages as random blocks with no hierarchy
- keep section order tied to the user journey
- identify what content is missing before polishing layout too early
- align page structure with conversion goals
