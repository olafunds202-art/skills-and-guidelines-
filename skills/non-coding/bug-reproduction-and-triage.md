# Skill: Bug Reproduction and Triage

## Purpose

Use this skill to turn vague bug reports into actionable engineering work.

## Workflow

1. Capture the report exactly.
2. Ask for environment, inputs, timing, and screenshots/logs if missing.
3. Define reproduction criteria.
4. Attempt reproduction in the smallest realistic environment.
5. Record whether the bug is reproducible, flaky, or unconfirmed.
6. Assess severity, scope, and likely affected users.
7. Convert findings into a clear implementation or investigation task.

## Triage outputs

- title
- severity
- reproducibility level
- environment
- reproduction steps
- affected scope
- evidence
- next owner/action

## Severity hints

- Critical: data loss, security issue, money movement issue, app unusable
- High: major feature broken, many users affected
- Medium: workaround exists, limited scope
- Low: cosmetic or low-frequency issue
