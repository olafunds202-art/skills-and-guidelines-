# Skill: Analytics and Conversion Checks

## Purpose

Use this skill when a project needs verification that key user actions are measurable and important conversion paths are functioning.

## Good use cases

- lead generation sites
- marketing pages
- booking or inquiry forms
- launches with tracking requirements
- post-launch QA

## Workflow

1. Identify the critical conversion events.
2. Identify the expected trigger point for each event.
3. Verify analytics or tag installation.
4. Test event firing where possible.
5. Verify thank-you, redirect, or confirmation flows.
6. Record gaps in measurement or attribution.

## Output format

- conversion actions
- expected events
- test result
- analytics notes
- missing tracking
- next actions

## Guardrails

- do not assume analytics is working because the script is present
- define the event names or goals clearly
- verify the user-visible conversion path, not just the tracker
- record what was tested vs what is still assumed
