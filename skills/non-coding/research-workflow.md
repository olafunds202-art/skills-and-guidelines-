# Skill: Research Workflow

## Purpose

Use this skill when you need to understand a problem space before implementing or deciding.

## Good use cases

- comparing technical options
- researching framework behavior
- checking current best practices
- gathering evidence before an architecture or product decision
- understanding an unfamiliar repository area

## Workflow

1. State the question clearly.
2. Define what decision or output the research should support.
3. Gather sources or code evidence.
4. Separate facts from assumptions.
5. Compare options with trade-offs.
6. Produce a concise recommendation.
7. List open questions that still block a final decision.

## Output format

- research question
- context
- findings
- options considered
- recommendation
- open questions

## Guardrails

- do not present assumptions as facts
- prefer directly relevant evidence over broad summaries
- cite external sources when current facts matter
- note uncertainty explicitly
