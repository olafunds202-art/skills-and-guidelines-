# Skill: Content and Asset Collection

## Purpose

Use this skill when a client project depends on content, branding, images, copy, credentials, or other materials not yet assembled.

## Good use cases

- brochure sites
- landing pages
- portfolio sites
- service-business websites
- projects blocked by missing content or branding

## Workflow

1. List every required content and asset category.
2. Mark what already exists, what is missing, and who owns it.
3. Define the required format for each item.
4. Identify dependencies between content and implementation.
5. Track approval status for draft vs final materials.
6. Escalate blockers early if missing inputs will delay delivery.

## Output format

- asset list
- content list
- owner
- format or source
- status
- due date
- implementation dependency

## Guardrails

- do not assume placeholder content is final content
- track source ownership for logos, photos, and brand assets
- identify which missing items block launch vs only polish
- keep a written content tracker for multi-page projects
