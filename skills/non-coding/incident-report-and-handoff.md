# Skill: Incident Report and Handoff

## Purpose

Use this skill when handing over the result of an outage, bug investigation, or difficult fix.

## Include

- what happened
- current status
- user impact
- what was changed
- what remains risky
- follow-up actions
- owner or next step where relevant

## Handoff format

### Summary
A short plain-language explanation.

### Status
- resolved / mitigated / monitoring / unresolved

### Impact
- who or what was affected

### Evidence
- logs, screenshots, traces, or reproduction notes

### Changes made
- files, config, data, or process changes

### Remaining risk
- what is still uncertain or fragile

### Follow-up
- tests to add
- monitoring to add
- docs to update
- cleanup to do later
