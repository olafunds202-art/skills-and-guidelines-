# Skill: Client Discovery and Intake

## Purpose

Use this skill when a client project is still being defined and you need to turn conversations into a buildable brief.

## Good use cases

- new website projects
- redesigns
- landing pages
- client dashboards or portals
- projects where requirements are still conversational

## Workflow

1. Identify the project goal.
2. Identify the audience and primary user journeys.
3. Gather required pages, features, and integrations.
4. Capture client-provided assets, content, and dependencies.
5. Record budget, timing, and launch constraints.
6. Identify decision-makers and approval points.
7. Produce a written brief and list open questions.

## Output format

- project summary
- audience
- goals
- required pages or features
- integrations
- client-provided assets/content
- timeline constraints
- approval contacts
- open questions

## Guardrails

- do not start implementation from vague promises alone
- record what the client must provide
- separate must-haves from nice-to-haves
- call out assumptions that could affect pricing or timing
