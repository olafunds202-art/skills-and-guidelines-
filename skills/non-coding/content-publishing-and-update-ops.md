# Skill: Content Publishing and Update Operations

## Purpose

Use this skill when websites or content systems need repeatable publishing and update workflows.

## Good use cases

- CMS-backed sites
- blog or news updates
- service-page refreshes
- recurring site content changes
- client content operations after handoff

## Workflow

1. Define who creates, reviews, and publishes content.
2. Define what needs review before publish.
3. Define content states such as draft, approved, published, archived.
4. Define how updates are logged or tracked.
5. Define rollback or revert behavior for content mistakes.
6. Define post-publish checks.

## Output format

- roles
- workflow states
- review steps
- publish steps
- rollback or revert steps
- post-publish checks

## Guardrails

- do not leave publishing ownership ambiguous
- define what counts as approved content
- keep content changes traceable
- include simple revert guidance for publishing mistakes
