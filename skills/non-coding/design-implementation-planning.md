# Skill: Design Implementation Planning

## Purpose

Use this skill when a UI or UX direction is known and the next step is turning it into an implementation plan.

## Good use cases

- component refactors
- layout redesigns
- new screen builds
- design-system alignment work
- staged UI overhauls

## Workflow

1. List the screens or components affected.
2. Group the work into reusable building blocks.
3. Identify style tokens, spacing rules, and layout systems involved.
4. Plan implementation order from foundations to screen-specific polish.
5. Define review checkpoints after each stage.
6. Define what visual verification is required.

## Output format

- affected areas
- component map
- style/layout foundations
- implementation phases
- review checkpoints
- verification approach

## Guardrails

- avoid one-shot screen rewrites when staged component work is safer
- separate structural work from polish work
- note where responsiveness or state variants could expand scope
- preserve existing behavior while improving presentation unless the behavior is intentionally changing
