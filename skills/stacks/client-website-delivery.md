# Stack Pack: Client Website Delivery

## Use when

- building a brochure site, landing page, company website, or small client web presence
- the project emphasizes content, responsiveness, SEO, forms, and deployment quality

## Working rules

- clarify the content model and navigation before heavy implementation
- prioritize responsiveness, accessibility, and performance early
- treat forms, analytics, and SEO metadata as first-class concerns
- keep handoff and maintainability in mind for the client team

## Common workflow

1. clarify sitemap, pages, and required sections
2. map reusable layout and component patterns
3. implement content structure before polishing micro-interactions
4. test mobile, tablet, and desktop layouts
5. verify forms, metadata, performance, and deployment readiness

## Verification checklist

- pages render correctly across breakpoints
- metadata, titles, descriptions, and social previews exist
- contact forms and integrations work
- images are optimized
- accessibility basics are covered
- deployment instructions are documented

## Common pitfalls

- building visual detail before the content structure is stable
- ignoring image optimization
- missing empty/error states on forms
- inconsistent spacing/typography systems
- no content-editing handoff notes for the client

## Delivery focus

- define deployment target early
- document domain, DNS, analytics, and form dependencies
- include clear post-launch follow-up items
