# Stack-Specific Skill Packs

These packs adapt the general Arena coding guidance to common stacks.

## Included starter packs

- `nextjs-typescript.md`
- `react-vite-typescript.md`
- `node-typescript-api.md`
- `python-fastapi.md`
- `python-scraping-automation.md`
- `flutter-dart.md`
- `chrome-extension.md`
- `google-apps-script.md`
- `supabase-postgres.md`
- `client-website-delivery.md`

## How to use

1. Start with the core operating guide and general skills.
2. Add the stack pack that matches the project.
3. Add project-specific rules only where the stack pack is still too broad.

## Notes

These are starter packs for v1.

If your project uses a different stack, add a new pack with:

- assumptions
- common workflows
- build/test/verify commands
- security pitfalls
- performance pitfalls
- file/layout conventions
